# Web Slicer — Project Instructions

Native macOS app (SwiftUI) that slices tall images into fixed-height PNGs for Figma.
Full behavior lives in [docs/spec.md](docs/spec.md) — keep it current when behavior changes.

## Build & test
- Project is generated by XcodeGen from `project.yml`. Don't hand-edit the `.xcodeproj`;
  edit `project.yml` and run `xcodegen generate`.
- Test: `xcodebuild test -scheme WebSlicer -destination 'platform=macOS'`
- Build: `xcodebuild build -scheme WebSlicer -destination 'platform=macOS'`

## Layout
- `WebSlicer/SlicePlan.swift` — pure math: source size + settings → output size + slice rects. No I/O.
- `WebSlicer/Slicer.swift` — ImageIO/CoreGraphics: read, scale, crop, write PNGs, pick output folder.
- `WebSlicer/SliceModel.swift` — runs slicing off the main thread, holds result lines, reveals folders in Finder.
- `WebSlicer/ContentView.swift` — the single window.
- `WebSlicerTests/` — Swift Testing. Seam and pixel round-trip tests are the safety net; keep them green.

## Conventions
- Work on feature branches; never commit to `main` directly.
- Pixels, never points, everywhere in the slicing code.

## Decision log
| Date | Decision | Why |
|---|---|---|
| 2026-10-15 | SwiftUI, macOS 26+, ad-hoc signed, no sandbox | Personal tool; sharing via README with Gatekeeper "Open Anyway" steps. Notarization ($99/yr) deferred. |
| 2026-10-15 | Sizes are actual image pixels | Figma's 4096 limit is on pixels. |
| 2026-10-15 | Two fields: Width (scale, downscale-only) and Height (slice), both default 4096 | Covers Figma's limit on both axes; never upscale (adds blur, no gain). |
| 2026-10-15 | Last slice is the remainder, never padded; fits-in-one still exports `-01.png` | Restacking must reproduce the source exactly; consistent output shape. |
| 2026-10-15 | Output folder `<name> slices/` next to source, suffix on collision, reveal in Finder | Zero-click like AppCleaner; never overwrite. |
| 2026-10-15 | Always PNG, preserve color profile | Lossless; avoids JPEG generation loss and P3 shifts. |
| 2026-10-15 | Fields: integers, min 100, no max, empty → 4096, persisted | Prevents accidental thousands-of-files; other tools have other limits. |
| 2026-10-15 | Batch drops processed independently; non-images skipped and listed | Same loop, no surprise rejections. |
| 2026-10-15 | URL capture is phase 2 | Basic WKWebView snapshot is ~1 day; robustness (lazy-load, sticky headers) is multi-day. |
| 2026-10-15 | XcodeGen for the project file; `.xcodeproj` is gitignored | Readable, diffable `project.yml` is the single source; run `xcodegen generate` after cloning. |
